# Analytics Engineering Portfolio

An end-to-end analytics engineering project demonstrating a modern data stack using Snowflake, dbt, Python, dimensional modeling, data quality testing, orchestration, and CI/CD.

The project models a multi-channel outdoor tourism business, integrating advertising, web analytics, customer, and booking data into a reliable analytics platform for acquisition, revenue, and customer performance reporting.

## Architecture

Data Sources → Python Ingestion → Snowflake → dbt → Analytics Marts → BI
